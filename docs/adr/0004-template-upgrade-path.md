# 0004 · 模板升级路径：先文档式，稳定后迁移 Copier

状态：已接受
日期：2026-10-03
决策人：Mengshi（用户确认）

## 背景

母版持续演进，已生成项目需要同步母版的后续更新。
生成器只做初始脚手架，没有升级命令。

## 决策

分两阶段：

1. **现在（模板大改期）**：文档式。每次母版变更写 `docs/changelog/YYYY-MM-DD-标题.md`。除 `docs/changelog/README.md` 外，每条必须有 `## 变更` 和 `## 已生成项目同步`。`make check-docs` 检查标题，并且至少有一条记录。生成项目按条目手工合并。
2. **模板稳定后**：一次性迁移到 [Copier](https://copier.readthedocs.io/)，用 `copier update` 做 3-way 合并。

## 备选方案

- **自研 update 模式**：需要自己实现模板文件、用户改动和冲突呈现。否决。
- **现在就上 Copier**：模板还在大改期，此时锁定 Copier 模板格式会拖慢母版本身。否决（留待阶段 2）。

## 后果

- 阶段 1 的同步说明写在 `docs/changelog/`，不散落在审计记录里。
- 阶段 2 的 Copier 迁移约等于重做生成器的大部分工作，届时单独排期。
- 在 Copier 迁移完成前，不承诺一键升级。
