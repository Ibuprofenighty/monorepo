# 11 · 从初始化到功能交付的执行流程

版本：2.0｜日期：2026-10-02｜本文件定义工作步骤；目录顺序不是开发顺序。

[返回总入口](../../README.md) · [项目选型](00-PROJECT-PROFILE.md) · [模板](12-TEMPLATES.md) · [Agent 入口](../../AGENTS.md)

## 1. 一次性初始化

填写 project-profile；选择客户端；决定身份/授权权威、数据库和部署；建立 workspace 和真实锁文件；实现最小生成/构建/测试命令；完成一条“客户端 → 后端 → 数据库”的真实功能路径。

初始化只搭运行闭环必需的骨架，不先实现全公司的所有权限、消息和 AI 平台。模板中的可选目录不创建空壳，未选择客户端不初始化。

## 2. 每个功能重复的主流程

```text
需求与不变量
  → 契约 + 权限规则 + 数据/并发设计
  → 验收场景和 oracle
  → 一个测试 Red
  → 该行为所需的 Feature + Auth + DB 实现
  → Green + 必要重构
  → 下一个场景
  → 真实集成/E2E/安全/迁移验证
  → 文档与证据同步
```

此流程是本母版选定的工作方式，不是把五类文件排成全项目只走一次的瀑布。纯规则可以先于某个适配器编码，权限规则不能等全项目功能写完才设计。

## 3. 开工检查：需求是否足够明确

确定用户要完成的行为、业务成功标准、禁止状态、公开接口变化、错误码、主体/资源来源、数据归属、存量影响和客户端范围。

可从代码/文档可靠确定的信息先查，不重复向用户询问已给出的答案。真实业务或安全规则缺失时不能由 Agent 随意发明；明确假设、限制当前切片范围，并标记阻塞决策。

## 4. 输出实施计划

计划按文件和模块列出修改、删除、生成产物、迁移与测试。每项有完成判据、依赖、风险和证据。不能只写“优化架构”“完善测试”而没有目标路径与可检验结果。

计划不是第二份需求权威；引用 spec/ADR。完成后从当前任务入口退出，留下绑定 commit 的简短结果，不继续生成互相冲突的 FINAL 文档。

## 5. 先定义验收，不先堆全项目测试

先列当前功能场景，选一个实现测试；确认失败来自尚未满足的行为，而非环境坏了。实现最小正确行为，运行相关旧测试，再重构。不要先生成几千行空测试骨架，之后根据实现反向填答案。

先代码后补回归的维护任务也必须明确 oracle 和证明缺陷可被测试检出；不能伪称执行过不存在的历史 Red。

## 6. 纵向交付边界

一个完整功能可能同时修改 contract、generated SDK、后端用例、授权接入、迁移、客户端、错误提示和操作文档。它们共同构成功能交付，不要把只有 API 200 的半条链路宣称完成。

后端共用一个用例，HTTP/worker/CLI 只适配；多个客户端可以各有 UI，但共用业务权威。Mock 与真实 API 用同契约，不做第二套 Demo 业务。

## 7. Agent 协作

总负责人拥有需求解释、边界和验收结论；子任务按模块/文件所有权分配。合约、根配置、数据库迁移和公共生成器设置单一合并负责人，避免多个 Agent 同时改同一真源。

子 Agent 交付差异、实际命令和证据，不只交付“已完成”。总负责人独立重跑关键验证，检查跨模块一致性与负向场景；模型更强不取消这一步。

不得让一个 Agent 同时偷偷修改 spec 和测试，把失败合法化。需求变更必须有显式理由与批准，再更新测试。

## 8. 审查与合并

审查功能正确性、依赖边界、权限覆盖、错误协议、并发/数据风险、外部副作用和真实客户端行为。`make verify` 运行项目已定义的合并 gate。失败要修复或明确阻塞，不以“本地大概没问题”覆盖。

代码、规范、生成物有冲突时解决为一个目标；不是添加 `compat`、`legacy`、第二个接口实现来隐藏冲突。确有外部版本约束先制定安全迁移，不盲删线上仍使用的契约。

## 9. 发布与完成报告

完成报告包括：实现范围；变更和删除位置；契约/错误/权限/数据影响；执行过的命令和结果；未执行项；残余风险；制品和回滚/恢复说明。

“文档写完”“lint 通过”“mock 通过”“编译成功”“开发者工具可加载”“真机 E2E 完成”“平台发布成功”是不同状态，必须分别说明。

## 10. 功能完成定义

需求与场景已定；错误与契约一致；权限涵盖所有入口；数据迁移安全；前端可运行且接真实后端；关键失败和副作用断言有效；选中 gate 通过；文档同步且无平行过期实现。

没有执行证据的项目不标记 PASS；重要阻塞没有解除的功能不标记完成。目录齐全和类型通过都不能单独证明业务功能交付。
